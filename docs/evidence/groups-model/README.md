# Stored Groups: browser consumer evidence

These are synthetic Board fixture captures from the Groups model/store change,
using `web/src/world/BoardView.browser.tsx?mode=preview`. All labels and statuses
are fixture data. They show the existing Board after the Team-only consumer
adaptation, not a Groups roster or new Pod frames. The canvas is pannable;
phone/portrait detail levels intentionally show fewer cards.

The five exact viewports are 390 × 844 (phone), 1440 × 900 (laptop),
2560 × 1440 (wide), 1280 × 1440 (half) and 1080 × 1920 (portrait).
Captures used headless Chrome and the repository's rendering flags under the
shared browser queue. Every image was inspected for private data and controls.
The new model, role transfers and persistence are verified by the service and
shared-property tests; the images do not claim new UI behavior.
