# Herdr World 0.2.0 release candidate 2

RC2 keeps the Office, Tree, Graph, and Spaces foundation from RC1 and fixes two
upgrade issues found during testing:

- Herdr plugin actions and the panel now work when Bun is absent from the running
  Herdr server's `PATH`. Bun is still needed while installing the plugin.
- A port collision now explains how to keep the existing World process and choose
  a persistent alternate port. The default remains 8787.

Herdr remains a separate runtime. Linux, macOS, and Windows x64/ARM64 archives,
the Herdr plugin, npm, and Homebrew RC Formula share version `0.2.0-rc.2`.

## Install and test

Install the candidate through your preferred channel:

```bash
npm install --global @ivoryheart/herdr-world@0.2.0-rc.2
herdr plugin install IvoryHeart/herdr-world --ref v0.2.0-rc.2 --yes
brew upgrade IvoryHeart/tap/herdr-world-rc # existing RC Formula, after the tap PR merges
```

For a new Homebrew installation, use `brew install IvoryHeart/tap/herdr-world-rc`
after the tap PR merges. For the standalone installer, set
`HERDR_WORLD_VERSION=0.2.0-rc.2`. Reinstall the
plugin to replace RC1's cached action commands. Test its `version`, `status`, and
panel from a running Herdr server, along with local/SSH connections and the main
views. Report defects against `v0.2.0-rc.2`; fixes will get another RC.

Before upgrading from 0.1.1, stop the old World process or assign a different
port. Old bridge profiles and browser preferences are not imported. See the
[deployment guide](https://github.com/IvoryHeart/herdr-world/blob/main/docs/DEPLOYMENT.md)
for migration steps. This RC does not replace GitHub Latest or npm `latest`.
