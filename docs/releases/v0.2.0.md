Herdr World 0.2.0 replaces the Herdr Web based application with one Bun service
and same-origin Web/PWA derived from Roamgate v0.7.11. It connects to separately
running Herdr 0.9.0 or newer servers through local sockets or managed OpenSSH
profiles. See the [deployment guide](https://github.com/IvoryHeart/herdr-world/blob/main/docs/DEPLOYMENT.md)
for setup and the full [changelog](https://github.com/IvoryHeart/herdr-world/blob/main/CHANGELOG.md).

### Upgrade from 0.1.1

- Stop the old World process before upgrading; both versions use port 8787 by
  default. Existing bridge profiles and browser preferences are not imported.
  Recreate local or SSH profiles after installation; old files remain available
  for rollback.
- The service now owns all Herdr connections. Browsers use one World origin and
  select one operational host at a time. Remote browser bridge URLs and the old
  Host/Origin configuration have been retired.
- `herdr-world task-summary` remains available with an 80-character limit and
  session-bound expiry. Update hooks that use the removed `--clear` option.
- The native Capacitor Android package is retired. Use the responsive PWA on
  mobile; it requires a reachable World service and does not work offline.

### What is new

- Office, Tree, Graph, and Spaces share qualified terminal, file, change, and
  agent-history views. The selected host can be local or reached through SSH.
- Shared Inspector windows can be arranged, moved, resized, and focused across
  visual views. Graph adds explicit arranging and rotation.
- Agent checkout context, session task summaries, pane pins, visual Actions,
  bounded multi-host observation, and optional Office metrics are available.
- Six desktop archives cover Linux, macOS, and Windows on x64 and ARM64. The
  standalone installer, npm package, and Herdr plugin use the same release
  binaries. A Homebrew Formula update follows in a reviewed tap pull request.

Herdr remains a separate runtime. See [security guidance](https://github.com/IvoryHeart/herdr-world/blob/main/SECURITY.md)
before making the World listener reachable from another device.
