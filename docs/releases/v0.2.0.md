# Herdr World 0.2.0

Herdr World 0.2.0 brings your agent work into one place. It replaces the 0.1.1
Herdr Web application with a new World service and a responsive Web app. Herdr
remains a separate runtime.

## See and control agent work

- **Office** shows agents at their desks, with attention and completed work easy
  to spot. **Tree** follows the host, workspace, and agent hierarchy. **Graph**
  maps their relationships. **Spaces** keeps the full terminal workspace close.
- Open an agent's terminal, files, changes, and history from any view. Keep several
  Inspectors open, move or resize them, and arrange their windows without losing
  the conversation you were following.
- Pin agents and panes, see session task summaries and checkout context, and use
  Actions to open the right detail or return to the right workspace. Optional
  Office metrics add an economy board when configured.
- Connect to local Herdr or add an SSH host. Switch the selected host to work in
  its views while World continues to observe your other connected hosts.

## Install on your platform

One version covers Linux, macOS, and Windows on x64 and ARM64. Choose a standalone
archive or npm; Linux and macOS also offer an installer and Homebrew. The Herdr
plugin can manage the same World service. The responsive PWA is available on
desktop and mobile when the service is reachable. [Installation and service setup](https://github.com/IvoryHeart/herdr-world/blob/main/docs/DEPLOYMENT.md)
includes checksums and platform instructions.

## Upgrade from 0.1.1

- Stop the old World process before starting 0.2.0 on the default port 8787, or
  configure a persistent alternate port. The installer can replace the launcher
  without removing the old bundle, which remains available for rollback.
- Recreate local and SSH connection profiles. Old bridge profiles and browser
  preferences are not imported. Browsers now use one World address; the former
  remote bridge URLs and Host/Origin settings no longer apply.
- Update hooks that use `herdr-world task-summary --clear`. Summaries now follow
  the current pane session and expire automatically.
- The native Android package is retired. Install the PWA on mobile and keep the
  World service reachable; the PWA does not work offline.
