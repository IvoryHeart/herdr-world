# Herdr World 0.2.0

Herdr World 0.2.0 brings your agent work into one place. It replaces the 0.1.1
application with a new World service and responsive Web/PWA app. Herdr remains a
separate runtime.

## What's new

- **Office, Tree, Graph, and Spaces** show agent work from different angles.
  Open an agent's terminal, files, changes, and history from any view, and keep
  several movable Inspectors open as you work.
- Pin agents and panes, see session task summaries and checkout context, and
  follow Visual Actions to the right detail or workspace.
- Connect to local Herdr on every desktop platform, or add SSH hosts on Linux
  and macOS. Switch hosts in one World service while other connections remain
  visible in the background.

## Install

One version covers Linux, macOS, and Windows on x64 and ARM64. Choose an archive,
npm, or the Herdr plugin; Linux and macOS also offer a standalone installer and
Homebrew. The PWA works on desktop and mobile when World is reachable. See
[installation and service setup](https://github.com/IvoryHeart/herdr-world/blob/main/docs/DEPLOYMENT.md)
for commands and checksums.

## Upgrade from 0.1.1

- Stop the old World process before starting 0.2.0 on port 8787, or choose a
  persistent alternate port. Recreate connection profiles; old bridge profiles
  and browser preferences are not imported.
- Update hooks using `herdr-world task-summary --clear`; summaries now expire
  with the agent session.
- The native Android package is retired. Use the PWA with a reachable World
  service; it does not work offline.
