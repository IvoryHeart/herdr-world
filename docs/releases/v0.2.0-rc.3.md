# Herdr World 0.2.0 release candidate 3

RC3 carries the Office, Tree, Graph, and Spaces experience from RC2. It focuses
on upgrades and service setup:

- Supervised standalone RC installs can now find newer RCs and the eventual
  stable release through the in-app update check. Homebrew, npm, and Herdr plugin
  installs can check for updates but upgrade through their own channels.
- On macOS, service installation now reports when another app owns the selected
  port instead of appearing to start successfully. Replacing an existing World
  service allows a brief handover.
- The app menu now links to the tutorial, features, troubleshooting, and issue
  reporting guidance.

Herdr remains a separate runtime. The six Linux, macOS, and Windows x64/ARM64
archives, Herdr plugin, npm, and Homebrew RC Formula share version `0.2.0-rc.3`.

## Install and test

Choose one installation channel:

- npm: `npm install --global @ivoryheart/herdr-world@0.2.0-rc.3`
- Herdr plugin: `herdr plugin install IvoryHeart/herdr-world --ref v0.2.0-rc.3 --yes`
- Homebrew, after the tap PR merges: `brew upgrade IvoryHeart/tap/herdr-world-rc`
  or `brew install IvoryHeart/tap/herdr-world-rc` for a new installation.
- Standalone installer: set `HERDR_WORLD_VERSION=0.2.0-rc.3`.

Test the RC2-to-RC3 upgrade, macOS port conflicts, local and SSH hosts, and the
four views. Report defects against `v0.2.0-rc.3`; fixes will receive another RC.

Before upgrading from 0.1.1, stop the old World process or choose a persistent
alternate port. Recreate connection profiles; old bridge profiles and browser
preferences are not imported. See the
[deployment guide](https://github.com/IvoryHeart/herdr-world/blob/main/docs/DEPLOYMENT.md)
for migration steps. This RC does not replace GitHub Latest or npm `latest`.
