# Herdr World 0.3.0-rc.1 release candidate

This candidate brings a more useful Town, shared attention and review, durable
World state and the latest integrated Roamgate features since World 0.2.7.
It includes the Town and Board navigation, attention and usage improvements
merged before this refreshed candidate was prepared.
Test it across the supported platforms before preparing stable 0.3.0. Corrections
after publication receive a new RC number.

World is derived from Roamgate main after v0.8.13 at
`2b16e991eeb2e90f55c948e249acaef1497d5254` and compatible with the separately
installed Herdr 0.9.5 (terminal protocol 22). Roamgate v0.8.14 and v0.8.15
are not integrated. World and Roamgate have independent version numbers;
World's previous stable release is 0.2.7.

## What's new

- **A town to work in:** generated woods, gardens, ponds and lanes surround the
  buildings. The town center opens common actions. Reception is upstairs and
  the lounge downstairs; each building has a fixed **+ Add room** doorway.
  Move and tidy rooms, filter which agents come to reception, and inspect room
  and table cards. New agents arrive on foot, and changing rooms and hosts
  preserves the view with less redraw work. A post office beside the town
  center collects your open pull requests, including those whose agents have
  gone, with ready-to-merge parcels first.
- **Fuel and expenses:** Town's board shows Codex and Claude subscription
  windows, percent left, reset times and reading age. Claude agents launched
  from World supply limits through a per-launch status line tap without editing
  Claude settings. The City expenses billboard and each building's reception
  show harness-log usage for Claude Code, Codex, Pi and Gemini, with optional
  local price estimates. Missing, partial, stale and unpriced data say so.
- **Context and limits at a glance:** agent peeks and windows show context
  fill from supported Claude, Codex, Pi and Gemini logs, with a sweat drop at
  85% or more. Unknown windows show no bar. Codex and Claude agents stopped
  on a usage limit stay slumped at their desks with an empty fuel can and
  reset clock; they clear when the reset passes or work resumes. Working
  agents show their current step in a thought bubble, amber when unusually
  long, with more detail as you zoom in.
- **Find your way through a busy Town:** lenses colour Town and Board by idle
  time, spend, pull requests, quests or harness. Search matches words in any
  order across Town, Board and Desk; Town highlights matches on the map and
  moves the camera to a chosen result. Desktop search unfolds from an icon
  with **/** or **Ctrl+F** (**Cmd+F** on Mac). Off-screen attention arrows and
  **N** / **Shift+N** take you through Needs you in order. The Town Master
  greets each visit with **Since you left**, with a browser-local opt-out.
- **Board shares Town's facts and actions:** its summary, host zones and rooms
  show counts, expenses and limits; agent cards show working steps, review
  state and idle time. Rename, close or reorder rooms and tabs, peek at an
  agent, answer its question and mark finished work reviewed from Board.
- **One Needs you tab:** questions, blocked agents and finished work appear
  beside every view, with quick answers, review marks, dismissal and Chat.
  Answers can include files and screenshots. Review marks follow you across
  views and browsers. Saved-answer delivery has an Outbox with explicit
  recovery controls; an uncertain send is never automatically repeated.
- **Put agents in the bin:** drag an agent onto Town or Board's bin, a Town bus
  stop, or use its window menu. Town's bus collects waiting agents on its
  four-minute route and closes them after leaving the screen. The tray offers
  **Put back** and **Close now**; restarting World closes no waiting agent.
- **Chat and phone improvements:** answer supported Claude forms, trust
  questions and Codex choices, and navigate supported command menus in Chat.
  Read complete questions or switch to Terminal when they cannot be answered
  safely. Chat source links open in the same window. Minimize agent and
  terminal windows, then restore them from a chip on phones. Town's room
  controls have larger touch targets, and opening Chat no longer resizes an
  unseen terminal.
- **Shared, durable state:** questions, answers, results, profiles, chimes,
  Board state and runtime status now use the instance's SQLite database, with
  private backups and imports of existing JSON. Terminal appearance, review
  marks and more settings follow the service across browsers. Connection and
  session checks fence saved operations against replacement runtimes.
- **More from the integrated source:** Spaces gains an **All servers** list,
  cross-server Pane Search and richer tab chips. Worktree placement and host
  commands are configurable. Mobile shells can launch saved agent commands;
  History Chat gains terminal input, image uploads and speech. Ranger supports
  the service account's Claude CLI and broader task scheduling. PDF previews
  work on browsers without a native viewer. SSH commands, reconnects and
  shared observations do less redundant work, and security dependencies have
  been refreshed.
- **An updated introduction:** the project site's 88-second **Promoted to CEO**
  film now shows today's Town, the bin bus, hiring, fuel and expenses, a phone
  answer at 3 AM and a morning recap over a 291-agent town. The film is drawn
  live with Town's code. Site deployment follows its separate main/stable
  publication policy; publishing this RC does not deploy the site.

These highlights are compiled from all 136 current `changes/` fragments.
Candidate preparation leaves those fragments and the Unreleased changelog
open; stable preparation assembles them into the dated 0.3.0 changelog.

## Upgrade from World 0.2.7

Before upgrading, stop your World service and back up its entire private data
directory, including SQLite WAL files if present. Back up an overridden legacy
ledger separately. Preserve configuration, connections, secrets and browser
storage. Restart only the World instance being upgraded; Herdr remains a
separate runtime.

World imports existing JSON into its private `world.sqlite` and retains private
backups. A binary predating SQLite cannot see new database answers or edits.
Do not downgrade by copying only the database or mixing WAL files; use a
matching whole-directory backup with World stopped. Some old completion marks
without current session proof may require review once again. See the
[backup and recovery guide](https://github.com/IvoryHeart/herdr-world/blob/v0.3.0-rc.1/docs/DEPLOYMENT.md#durable-questions-results-and-backups).

After this candidate is published, install its exact version with:

```bash
npm install --global @ivoryheart/herdr-world@0.3.0-rc.1
```

Alternatively, use its platform archive, the Unix installer with
`HERDR_WORLD_VERSION=0.3.0-rc.1`, or the separate
`IvoryHeart/tap/herdr-world-rc` Formula after its tap PR is reviewed and merged.
The six Linux, macOS and Windows x64/ARM64 archives remain available. npm needs
Node.js 22.14.0 or newer. Source builds now require Bun 1.4.4 or newer; installed
archives and plugins need no external Bun.

The standalone installer and Homebrew now preserve an existing Herdr and install
the verified runtime only when it is missing. Homebrew's first normal launch
does this outside its keg, without a required Herdr Formula or Intel source
build. A failed optional runtime setup warns while leaving World available for
SSH connections and in-app setup. Fresh standalone installs leave harness
integration and plugin refresh to an explicit `herdr-world herdr upgrade`.
Use `herdr-world herdr upgrade --install` when explicitly installing or upgrading
Herdr and its integrations. `HERDR_WORLD_SKIP_HERDR=1` still selects a World-only
standalone installation. Explicit World updates retain their separate Herdr
upgrade step and reported restart or package-manager instructions.

RC publication uses GitHub prerelease status, npm's `next` tag and the separate
Homebrew RC Formula. It does not change stable Latest channels or deploy the
project site. Before merge, the release PR's `release-preview` label requests
six platform archives, npm packages and a Homebrew preview from CI; see
[pre-merge previews](https://github.com/IvoryHeart/herdr-world/blob/v0.3.0-rc.1/docs/release.md#pre-merge-platform-previews). Those binaries
identify themselves as `0.0.0-rc.<CI run number>`.

## Important limits

- Herdr cannot make prompt input conditional on an unchanged recipient. Chat
  answers and Board sends check before submission, but a concurrent replacement
  can still receive input. Inspect an uncertain receipt before retrying; see
  [issue #284](https://github.com/IvoryHeart/herdr-world/issues/284).
- Automatic saved-answer delivery requires a newly verified local Linux CLI
  recipient in a supported Chat session. Other asks remain retrievable with
  `herdr-world ask get`. Restarted World instances retain records but cannot
  prove authority to replay old sends. Use the Outbox to inspect uncertainty.
- Subscription gauges reflect observed harness records, not live billing
  guarantees. Claude needs a World-launched agent with the status line tap;
  its first reading may take about a minute after an answer. Expense estimates
  need a local price table, and incomplete sources remain visibly incomplete.
  City and building boards share the same UTC totals and keep caveats
  accessible on hover or tap. Context bars need an attributable current
  session and a known context window; missing evidence is never shown as zero.
- Remote Windows file and Git tools and Windows harness readiness probes
  remain unavailable. Manage connections has no remote upgrade control.
  Service-owned SSH forwarding is present, but device-facing forwarding
  controls are not included.
- Work-item quests and the proposed per-harness World integration package,
  including its Settings rows and separate Claude limits tap work, are not
  shipped by this candidate. macOS signing and notarization remain open.
  The command-box and search-over-lens follow-ups are also excluded; the
  merged desktop search icon and current lenses are included.
