# Herdr World 0.3.5

World now runs on herdr-core as well as the Herdr TUI, and Town shows status with light.

## What's new

- **herdr-core support.** Use herdr-core beside the Herdr TUI or on its own, locally, over SSH (Unix or Windows), or on the same Windows computer. Core agents appear in Town, Board, Desk and Needs you, and open in the same Chat, Terminal, Files and Changes windows. With no runtime installed, World installs herdr-core for you. See [Runtimes](https://github.com/IvoryHeart/herdr-world/blob/v0.3.5/README.md#runtimes) for what each runtime supports.
- **Light is status.** Town has a time of day. Rooms with work are lit, idle rooms are dark, and amber means something needs you. The button under the zoom controls picks clock, day, dusk or night.
- **A calmer, bigger Town.** Quiet identity colours, sun and cloud shadows, lamps and fireflies, and a layout that stays readable with hundreds of agents. On phones, rooms sit three to a row.
- **Every pull request in one place.** The post office opens all pull requests in Board's Work lens.
- **Security fixes.** Dependencies are updated to fix known advisories.

## Upgrade from 0.3.0

Back up World's data directory first; see [backup and recovery](https://github.com/IvoryHeart/herdr-world/blob/v0.3.5/docs/DEPLOYMENT.md#durable-questions-results-and-backups).

```bash
herdr-world update
```

Homebrew: `brew upgrade IvoryHeart/tap/herdr-world` after the Formula update merges. npm: `npm install --global @ivoryheart/herdr-world@0.3.5` (Node.js 22.14.0 or newer). An existing Herdr TUI or herdr-core is kept as it is.

## Practical limits

- herdr-core support is verified with core 0.1.21. Changes in later core releases wait for a World update.
- Windows herdr-core is not yet tested on real Windows hardware.
- Usage readings can lag, and expenses are estimates.
- macOS downloads are unsigned and unnotarized.

See the [feature guide](https://github.com/IvoryHeart/herdr-world/blob/v0.3.5/FEATURES.md) for controls and limits, or follow the [tutorial](https://herdr.world/tutorial/).
