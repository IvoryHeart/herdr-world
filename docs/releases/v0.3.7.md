# Herdr World 0.3.7

0.3.6 was tagged but never published. 0.3.7 carries the same changes, plus a release-tooling fix.

World now remembers past agents, opens VS Code inside World, shows usage and what agents made, and starts herdr-core agents more reliably.

## What's new

- **Apartments for past agents.** Agents that are not running now live in Town's Apartments: search them, read their history, resume Claude and Codex agents into a room, or evict them for good. A Bin agent rides Town's bus there; the bin's countdown comes from the bus's route, so Town and every view show the same time.
- **VS Code inside World.** The new Code view, beside Town, Board and Desk, opens the VS Code installed on the computer a project is on, locally or over SSH, with your extensions and settings. Its server keeps running when you close the view or World restarts.
- **Memory, things agents made, and usage.** Town's Library shows what each agent and project remembers, which you can read, edit and delete, and a **Made by agents** tab with reports, pages and links agents made. The observatory shows each harness's 5-hour and weekly budget and opens **Usage**, with time at work, time waiting on you, tokens and cost per agent, project and day.
- **A fuller Town.** Weather and a Sky panel, a harbour with each open project's checks and releases, open pull requests as crates at the warehouse, and questions for you as letters at the post office. A working agent that has gone quiet for 10 minutes shows an hourglass. Each machine gets one building, with as many rooms per row as you choose, and Town pans and zooms at your display's full frame rate.
- **Find, set and learn from anywhere.** Cmd+K (Ctrl+K) finds any agent on every host and runtime, and Enter opens its terminal. Every setting now lives in one Settings home with its own search, replacing the Configuration dialog, and one **Integrations** screen lists runtimes, GitHub, Jira, usage and the vault. **What can I do here?** gives help on every screen, with a picture and **Try** for each entry.
- **Focus sessions.** Hold chimes, notifications and badge counts on every device for 25, 45 or 90 minutes, then get one chime and a recap.
- **Draw on Board.** Pen, shapes, text and arrows that attach to cards and notes, saved with the board.
- **Fixes for herdr-core and new agents.** New herdr-core agents get your shell's environment, such as tools added by bun or nvm. Starting one on a core host opens its window on the first click. Town can move core agents between desks and desks between rooms. A new Codex agent shows ready, not done, and core agents' questions alert you when core is the default host. Claude also starts again from **New agent** in Unix Herdr TUI rooms; in 0.3.5 its long status-line setting could be cut off and the agent didn't start.

## Upgrade from 0.3.5

Back up World's data directory first; see [backup and recovery](https://github.com/IvoryHeart/herdr-world/blob/v0.3.7/docs/DEPLOYMENT.md#durable-questions-results-and-backups).

```bash
herdr-world update
```

Homebrew: `brew upgrade IvoryHeart/tap/herdr-world` after the Formula update merges. npm: `npm install --global @ivoryheart/herdr-world@0.3.7` (Node.js 22.14.0 or newer). An existing Herdr TUI or herdr-core is kept as it is.

## Practical limits

- herdr-core support is verified with core 0.1.21. Changes in later core releases wait for a World update. See [Runtimes](https://github.com/IvoryHeart/herdr-world/blob/v0.3.7/README.md#runtimes).
- Windows herdr-core is not yet tested on real Windows hardware.
- Microsoft's VS Code in the Code view needs World on HTTPS or at localhost; code-server and OpenVSCode Server also work over plain HTTP.
- Usage readings can lag, expenses are estimates, and harnesses whose logs World doesn't read show time but no tokens.
- macOS downloads are unsigned and unnotarized.

See the [feature reference](https://herdr.world/features/) for controls and limits, [help](https://herdr.world/help/) for each screen, or follow the [tutorial](https://herdr.world/tutorial/).
