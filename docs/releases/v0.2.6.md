# Herdr World 0.2.6

Herdr World 0.2.6 adds Board and simplifies navigation to Town, Board, Desk and
Spaces. It is derived from Roamgate v0.8.5 at
`5ce1d8d620549226de76321303e7bffa911ae371` and compatible with Herdr 0.9.4
(terminal protocol 22). Herdr remains a separately installed runtime.

## What's new

- **Board:** arrange workspace and tab cards beside sticky notes, string notes
  to workspaces, tabs or exact panes, and explicitly send a note to an agent.
  Notes, strings and layout are saved by the World service across devices.
  Fold workspaces, zoom into pane rows, choose card colours, or use Tidy with
  Undo. Files, Changes and History share the same Inspector as Town and Desk.
- **Touch controls:** Town and Board share gesture handling. Hold a card still
  before dragging on phones; a quick swipe pans. Adding a second finger switches
  a drag to pinch zoom without committing the move. Board pauses settling while
  you type in a terminal and responds more quickly in large multi-host scenes.
- **Safer note sending:** World checks the runtime, pane, terminal and recorded
  recipient before sending. If another agent has taken over, Board asks before
  sending to that agent. A change detected during submission is reported as
  possibly delivered elsewhere, rather than as a successful send.
- **Terminal links on phones:** long-press offers Open link for visible URLs and
  paths while an agent repaints, including Town terminals with the Composer open.
  Desktop links use Cmd/Ctrl-click.
- **New terminals open where you can see them:** Board's New tab dialog opens
  above open terminal windows, and a terminal created while another is selected
  now opens instead of reporting "Tab created, but Inspector focus failed".
- **Refreshed guides and screenshots:** the tutorial, feature guide and website
  cover the four retained views, with Town and Board layouts and Board-backed
  Files, Changes and History captures.

## Upgrade from 0.2.5

Preserve your World configuration and connection profiles, then use your existing
installation channel's update flow. Town stays the default. Office, Tree and
Graph have been retired: `/office` and saved Office preferences open Town;
`/graph`, `/tree` and their saved view preferences open Board. Redirects replace
history entries. Inspector presentation and Town calm motion settings remain;
Office room alignment and long-title settings are removed. Optional Prometheus
cost metrics appear on the Town board.

After a Herdr restart, Board asks whether to Keep or Detach strings whose targets
need confirmation. Strings whose targets closed wait in Needs a home; notes
remain saved. Check the named recipient before sending a note.

Install this exact version through npm with
`npm install --global @ivoryheart/herdr-world@0.2.6`, or use the matching standalone
archive/installer from this release. Refresh an installed Herdr plugin through
its normal update flow. Homebrew availability follows review and merge of the
corresponding tap PR. No new sign-in migration is introduced. If upgrading
directly from 0.2.3, follow the
[0.2.4 sign-in migration notes](https://github.com/IvoryHeart/herdr-world/releases/tag/v0.2.4).
See the [deployment guide](https://github.com/IvoryHeart/herdr-world/blob/v0.2.6/docs/DEPLOYMENT.md)
for installation and service instructions.

## Known limits

- Choosing Claude or Codex in a new-tab or Board Start an agent dialog currently
  opens a shell rather than launching the selected agent. The launcher work is
  tracked in [issue #219](https://github.com/IvoryHeart/herdr-world/issues/219).
- Herdr cannot lock a pane between the recipient check and prompt submission.
  World checks again afterwards and reports a detected replacement as uncertain;
  it cannot guarantee atomic delivery through a concurrent replacement.
- Event traces and renderer counters are development tools and are absent from
  release builds. For a release-build bug report, describe the steps and observed
  result; see the [development guide](https://github.com/IvoryHeart/herdr-world/blob/v0.2.6/docs/development.md#development-tools)
  for diagnostics in a development build.
