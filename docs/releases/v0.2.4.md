# Herdr World 0.2.4

Herdr World 0.2.4 improves mobile navigation, desktop shortcuts, workspace tools
and plugin installation. It is derived from Roamgate v0.8.5 at
`5ce1d8d620549226de76321303e7bffa911ae371` and compatible with Herdr 0.9.4.
Herdr remains a separately installed runtime.

## What's new

- **Bun-free released plugins:** Unix and Windows installers download and verify
  the matching compiled World executable. Native plugin commands retain cached
  launcher actions, managed service behavior and World-owned updates. Source
  builds still require the pinned Bun toolchain.
- **Mobile navigation:** bottom navigation, terminal Back and workspace/tab
  controls, a one-tap Message composer and Direct input. Concurrent Inspector
  drafts and attachments survive input-panel reopening and host focus changes.
- **Desktop shortcuts and naming:** a searchable, read-only shortcut cheat sheet
  shows the active preset. Open it with Cmd+Shift+K on macOS or Ctrl+Alt+Shift+K
  on Windows/Linux. Workspace/worktree dialogs suggest readable two-word names
  while preserving manual edits and captured host ownership.
- **Workspace and Ranger tools:** installation-management commands, worktree PR
  badges, safer File Explorer mutations and paths, task-management proposals,
  workspace/agent mentions, model/thinking controls and provider error handling.
- **Windows SSH:** connect to running Herdr 0.9.1+ sessions through Windows
  PowerShell. Remote Windows file, Git and history tools remain unavailable;
  terminal and native workspace operations retain qualified connection ownership.
- **Authentication:** configured passwords accept 8–1024 Unicode characters.
  Startup warns below the recommended 15 characters for access beyond a trusted
  private network. Optional 6–12 digit PIN login is for private networks/VPNs,
  with separate throttling and password/token recovery.
- **Terminal fixes:** hidden-cursor IME positioning and input-composition fixes.
  Release validation now includes fresh installs and v0.2.3 upgrade/restart checks
  on all six supported native platforms, including execution without external Bun.

## Upgrade from 0.2.3

**Sign in again after upgrading.** This release migrates password-signed browser
cookies to independent, persisted session-signing state. Existing 0.2.3 sessions
are intentionally rejected; your configured password or persistent login token
remains the recovery credential. New sessions survive restart and are revoked
when configured credentials change. All listeners still require authentication.

Preserve your existing World configuration and connection profiles. Standalone,
npm and Homebrew installations retain their channel's update ownership. Refresh
an installed Herdr plugin through its normal update flow to obtain the current
manifest and native installer. There is no bundled Herdr runtime.

Install the exact version through npm with
`npm install --global @ivoryheart/herdr-world@0.2.4`, or use the matching desktop
archive/standalone installer from this release. Homebrew availability follows
review and merge of the corresponding tap PR. See the
[deployment guide](https://github.com/IvoryHeart/herdr-world/blob/v0.2.4/docs/DEPLOYMENT.md)
for installation, service, authentication and plugin instructions.

## Known issue

Dense synthetic browser workloads intermittently exceed existing input-latency
budgets. Earlier CI runs measured 277 ms against a 200 ms limit and 542 ms against
a 500 ms limit; later complete validation passed with the same code and unchanged
limits. The causes remain unresolved. Investigation and a fix are planned for the
next release in [issue #202](https://github.com/IvoryHeart/herdr-world/issues/202).
