# Herdr World 0.2.3

Herdr World 0.2.3 adds the Ranger workspace assistant and recent workspace,
mobile and Inspector improvements. It is derived from Roamgate
`d703e6f6b94bdd418186a8daaaea77bceb78d26c` and compatible with Herdr 0.9.0.

## What's new

- **Ranger** adds workspace chat, approval-based proposed actions, background
  and scheduled tasks, and monitoring alerts for permitted local and SSH
  workspaces.
- **Workspace tools** add commit history, file previews, tab pinning and
  reordering, pane movement, terminal font and input controls, uploads, and
  instance title settings.
- **Navigation and connection status** improve the floating mobile workspace
  navigator, Office redraw when returning from Ranger, and compact GitHub
  status and source controls in the Inspector.
- **Authentication** now requires login on every listener, including localhost.
  Configured passwords must contain 15–1024 characters. If no password is
  configured, World creates a persistent login token; repeated failed attempts
  are throttled.

## Upgrade

No data migration is required. After upgrading, authenticate in the browser even
when connecting through localhost. Configure `HERDR_WORLD_PASSWORD` with a
15–1024-character password, or use the persistent login token created by World.
See the [deployment guide](https://github.com/IvoryHeart/herdr-world/blob/main/docs/DEPLOYMENT.md)
for login and connection setup.

Install through the desktop archives, npm, the Herdr plugin, or Homebrew on
Linux and macOS. See the [full changelog](https://github.com/IvoryHeart/herdr-world/blob/main/CHANGELOG.md)
and [security guidance](https://github.com/IvoryHeart/herdr-world/blob/main/SECURITY.md).
