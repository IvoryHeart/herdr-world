# Herdr World 0.3.0-rc.3 release candidate

This candidate makes upgrades easier to finish, sets up World skills for your
agent tools automatically and clears stale usage-limit notices. Here is what
changed since rc.2, followed by what 0.3.0 brings to your workspace overall.

Test the candidate across your devices before stable 0.3.0; corrections after
publication receive a new RC number.

## Changed since rc.2

- **Finish an upgrade in one run.** Rerunning the standalone installer now
  finishes like `herdr-world update`: it brings your local setup up to date
  and restarts the matching running World service on Linux or macOS. Output
  tells you what changed and whether you need to restart anything yourself.
- **Give agents World skills without separate setup.** Standalone installs and
  World updates find configured agent tools and install or refresh their World
  integrations, so agents can ask you questions, share results and report
  progress. Claude's usage readings are set up too. Set
  `HERDR_WORLD_SKIP_INTEGRATIONS=1` to keep setup manual; integrations you
  explicitly removed stay removed, and your own skills are preserved.
- **Trust that an old usage stop will clear.** Chat and task status now refresh
  usage-limit notices after rapid conversation updates, so a stale notice no
  longer makes an agent look blocked.

## Install or upgrade

**Already on rc.2?** Back up your private World data, then install this exact
candidate through your existing channel. There is no additional data migration
specific to rc.3, and platform support is unchanged.

After rc.3 is published, upgrade a standalone Linux or macOS installation with:

```bash
curl -fsSL \
  https://github.com/IvoryHeart/herdr-world/releases/download/v0.3.0-rc.3/install-herdr-world.sh \
  | HERDR_WORLD_VERSION=0.3.0-rc.3 sh
```

The installer restarts a matching running managed World service. Restart an
unmanaged process, or a service you stopped for backup, yourself. To keep World
integrations manual, put `HERDR_WORLD_SKIP_INTEGRATIONS=1` beside
`HERDR_WORLD_VERSION` before `sh`.

For an existing npm installation, use:

```bash
npm install --global @ivoryheart/herdr-world@0.3.0-rc.3
```

Alternatively, use the exact candidate's platform archive, or upgrade the
separate `IvoryHeart/tap/herdr-world-rc` Formula after its tap PR is reviewed and
merged. Archives support Linux, macOS and Windows on x64 and ARM64. npm needs
Node.js 22.14.0 or newer; source builds need Bun 1.4.4 or newer. Installed
archives need no external Bun. Keep using one installation channel.

**Coming from World 0.2.7?** Stop World and back up its entire private data
directory, including SQLite WAL files if present, before upgrading. Back up an
overridden legacy ledger separately; preserve configuration, connections,
secrets and browser storage. World imports existing JSON into `world.sqlite`
and retains private backups. Older versions cannot see new database answers or
edits: to roll back, stop World and restore a matching whole-directory backup,
without mixing database and WAL files. Some older completion marks may need
review again. See the
[backup and recovery guide](https://github.com/IvoryHeart/herdr-world/blob/v0.3.0-rc.3/docs/DEPLOYMENT.md#durable-questions-results-and-backups).

This prerelease uses npm's `next` tag and the separate Homebrew RC Formula;
stable update channels are unchanged. Before publication, the release PR's
`release-preview` label requests platform archives, npm packages and a Homebrew
preview from CI. Follow the
[pre-merge preview instructions](https://github.com/IvoryHeart/herdr-world/blob/v0.3.0-rc.3/docs/release.md#pre-merge-platform-previews).
Preview binaries identify themselves as `0.0.0-rc.<CI run number>`.
RC publication does not deploy the refreshed public website.

## What 0.3.0 brings overall

World helps you find the right work, see which agents need you and review what
they finished across desktop and phone. These are the highlights since 0.2.7.

### Find work and keep it in sight

- **Search or act from one box.** Press **Ctrl+K** (**Cmd+K** on Mac) to find
  agents, terminals, rooms and buildings, switch views or run an action. In
  Chat, terminals and text fields, use **Ctrl+Alt+K** (**Cmd+Option+K** on Mac).
  On a phone, choose **Find or act** in the corner view menu.
- **Make sense of a busy workspace.** Search across Town, Board and Desk;
  highlight matching places in Town, or use lenses for idle time, spend, pull
  requests, quests and agent tools. Town's post office keeps open pull requests
  visible after their agents have gone. Spaces adds **All servers** and
  cross-server Pane Search.

### See where your attention will help

- **One Needs you tab across every view.** Find questions, blocked agents and
  finished work together. Answer, attach files, open Chat or mark work reviewed;
  review marks follow you across views and browsers. Off-screen arrows and
  **N** / **Shift+N** take you to the next item. The browser tab and supported
  app icons show the count while you work elsewhere.
- **See progress and remaining capacity.** Working agents show their current
  step in Town bubbles and Board cards; unusually long steps turn amber.
  Town's Fuel board shows subscription capacity and reset times. Usage-limit
  stops show a fuel can and reset clock. Expense boards and context indicators
  help you judge where to spend time, with stale or incomplete readings labelled.

### Organize agents and help them move forward

- **Manage work from Town or Board.** Add, move and tidy rooms, filter reception,
  inspect agents, answer questions and review finished work. Clear finished
  agents through the bin or Town bus, with **Put back** before they close.
- **Let agents keep you informed.** World skills teach agents to ask questions,
  save results and report progress. Install and update now set them up for
  configured tools; **Menu → Configuration → Integrations** gives you manual
  controls. Chat supports more question forms and choices, and its Outbox lets
  you inspect saved-answer delivery without repeating uncertain sends.
- **Keep Chat open through worktree changes.** Continue reading and messaging
  while Files, Changes and Commits recheck the agent's new folder or branch.

### Keep working across devices and visits

- **Keep conversations close.** Minimize windows into chips on a phone. On
  desktop, use **⋯ → Fit right** or **Fit left** to dock Chat or a terminal at a
  remembered width beside your work. PDF previews also work in browsers without
  a native viewer; History Chat supports terminal input, images and speech.
- **Return to a workspace that remembers.** Questions, answers, results,
  connection profiles, chimes and Board state survive restarts. More settings,
  terminal appearance and review marks follow the World service across browsers.
- **Learn with your own project.** The refreshed website, **Promoted to CEO**
  film and [tutorial](https://github.com/IvoryHeart/herdr-world/blob/v0.3.0-rc.3/docs/TUTORIAL.md)
  show how to delegate a small task, follow progress, review changes and pick up
  the workspace from your phone.

## Practical limits

- Automatic saved-answer delivery is limited to newly verified local Linux
  command-line agents in supported Chat sessions. After a World restart, old
  sends cannot resume automatically; check the Outbox.
- Usage and expense displays are observations, not live billing guarantees.
  Claude readings may take about a minute; estimates need a local price table.
- World skill controls apply locally; SSH skill installation is manual.
  Remote Windows file tools, Git tools and agent readiness checks remain
  unavailable. Work-item quests and macOS signing and notarization remain open.
