# Herdr World 0.2.1

Herdr World 0.2.1 adds a Desk for reviewing agent work across connected hosts,
supports concurrent local and SSH host contexts in one World, and improves
graphics efficiency in Office and Graph. Herdr remains a separate runtime.

## What's new

- **Desk** is the default view for triage across filtered hosts. Review questions,
  reports, live terminal output, turn details and edited files, then mark work
  for review with keyboard controls and undo. A docked reading pane keeps the
  queue visible while you inspect an agent.
- **Multi-host work** keeps terminals, Inspectors, resources, notifications and
  window arrangements attached to their owning connection while you switch
  filters and focus. Observation and search remain bounded across hosts.
- **Graphics efficiency** reuses Office rooms and artwork, prepares graphics in
  bounded tasks, and runs Graph physics in a worker. Input remains responsive
  during refreshes and terminal activity, with reduced-motion and hidden scenes
  avoiding unnecessary paints.

## Upgrade

Existing browser-local Desk review marks reset once because their storage scope
and receipt identities change for the aggregate multi-host Desk. Recreate any
connection profiles that were not present in your previous World installation.
See the [deployment guide](https://github.com/IvoryHeart/herdr-world/blob/main/docs/DEPLOYMENT.md)
for service setup and connection guidance.

Install through the six desktop archives, npm, the Herdr plugin, or Homebrew on
Linux and macOS. See the [full changelog](https://github.com/IvoryHeart/herdr-world/blob/main/CHANGELOG.md)
and [security guidance](https://github.com/IvoryHeart/herdr-world/blob/main/SECURITY.md).
