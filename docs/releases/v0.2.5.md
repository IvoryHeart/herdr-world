# Herdr World 0.2.5

Herdr World 0.2.5 introduces Town, a new default view for watching and working
with agents across your Herdr hosts. It is derived from Roamgate v0.8.5 at
`5ce1d8d620549226de76321303e7bffa911ae371` and compatible with Herdr 0.9.4.
Herdr remains a separately installed runtime.

## What's new

- **Town:** each host is a building, each workspace a room and each tab a team
  table. Agents that need you queue at reception; finished agents keep their
  work visible until reviewed. Zoom from the whole town to an individual desk,
  with a single-column layout on phones and an optional calm motion setting.
- **Replies beside your agents:** hover or tap an agent to see recent messages,
  questions, one-tap answers and a reply composer with attachments. The needs-you
  rail becomes a bottom tray on phones. Open Inspector for files, changes and
  agent history.
- **Move live work:** drag tables between rooms on the same host or agents
  between tables, with touch and keyboard controls. Agents keep running; failed
  moves attempt rollback, uncertain results stay visibly unresolved, and moving
  the last table out of a room asks for confirmation because that room closes.
  Closing a table also closes the gap it leaves in the room.
- **Mobile navigation:** the terminal's on-screen Back returns directly to the
  view with the composer open. The phone's Back closes the composer and terminal
  one layer at a time.
- **Updated guides and website:** refreshed Town, Office, Desk and Graph
  documentation, desktop/mobile Town previews and an updating latest-release
  badge. Versioned website assets prevent stale cached scripts and styles after
  deployment.

## Upgrade from 0.2.4

Preserve your existing World configuration and connection profiles. Town becomes
the default at the World root; Office remains available at `/office`, alongside
Desk, Tree, Graph and Spaces. No new sign-in migration is introduced by this
release. If upgrading directly from 0.2.3, follow the
[0.2.4 sign-in migration notes](https://github.com/IvoryHeart/herdr-world/releases/tag/v0.2.4).

Use your existing installation channel's update flow. Install this exact version
through npm with `npm install --global @ivoryheart/herdr-world@0.2.5`, or use the
matching standalone archive/installer from this release. Refresh an installed
Herdr plugin through its normal update flow. Homebrew availability follows
independent review and merge of the corresponding tap PR. Herdr is not bundled.
See the [deployment guide](https://github.com/IvoryHeart/herdr-world/blob/v0.2.5/docs/DEPLOYMENT.md)
for installation, service, authentication and plugin instructions.

## Known issue

Dense synthetic browser workloads intermittently exceed existing input-latency
budgets. Earlier CI runs measured 277 ms against a 200 ms limit and 542 ms against
a 500 ms limit; later complete validation passed with unchanged limits. The
causes remain unresolved; investigation is tracked in
[issue #202](https://github.com/IvoryHeart/herdr-world/issues/202).
