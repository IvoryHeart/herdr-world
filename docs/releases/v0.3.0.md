# Herdr World 0.3.0

Spend less time checking agents and more time moving work forward. World 0.3.0
brings questions, progress and finished work into view, helps you find the right
conversation, and remembers your workspace when you return on another device.
These are the highlights since 0.2.7.

## Find work, answer questions, keep moving

- **Find or act from one box.** Press **Ctrl+K** (**Cmd+K** on Mac) to find an
  agent, terminal, room or building, switch views or run an action. While typing
  in Chat or a terminal, use **Ctrl+Alt+K** (**Cmd+Option+K**). On a phone,
  choose **Find or act** in the corner view menu.
- **Give your attention where it helps.** The **Needs you** tab gathers
  questions, blocked agents and finished work across views. Answer with
  attachments, open Chat or mark work reviewed; review marks follow you across
  browsers. Town's arrows lead you to work outside the screen.
- **See progress and capacity at a glance.** Town bubbles and Board cards show
  each working agent's current step. Fuel gauges show subscription capacity and
  reset times; expense boards and context indicators help you plan your next
  task. Claude limits keep the highest reading within each window, and Board's
  host headings keep usage summaries readable.
- **Keep a busy workspace organized.** Search Town, Board and Desk, use lenses
  for idle time, spending, pull requests and quests, and move or tidy Town rooms.
  The post office keeps open pull requests visible after their agents leave.
  Clear finished agents through the bin or bus, with **Put back** before closing.
- **Help agents report back.** World skills are set up automatically for
  configured agent tools, helping agents ask questions, share results and
  report progress. Chat supports more question forms and choices; its Outbox
  shows saved-answer delivery. Chat stays open while an agent changes worktree.
- **Pick up where you left off.** Questions, answers, results and workspace
  settings survive restarts, with more preferences shared across browsers.
  Minimize windows into chips on a phone, or use **⋯ → Fit right** / **Fit left**
  on desktop to keep Chat or a terminal beside your work. PDF previews work
  without a native viewer. The refreshed [website](https://herdr.world/) and
  [tutorial](https://herdr.world/tutorial/) walk through delegating, reviewing
  and continuing from your phone.

## Upgrade from 0.2.7

Stop World and back up its entire private data directory, including any SQLite
WAL files, plus any separately configured legacy ledger. Preserve your browser
storage too. World imports existing saved data into its database; older versions
cannot read new answers or edits. A rollback needs the matching whole-directory
backup, without mixing database and WAL files. See
[backup and recovery](https://github.com/IvoryHeart/herdr-world/blob/v0.3.0/docs/DEPLOYMENT.md#durable-questions-results-and-backups).

For a standalone installation, after 0.3.0 is published, run:

```bash
herdr-world update
```

After upgrading from 0.2.7, run `herdr-world update` once more to set up World
skills and Claude usage readings for configured agent tools, even when already
current.

From 0.3.0 onward, updates restart the matching running managed World service on
Linux and macOS and set up these integrations automatically. If you stopped World
for backup, start it again after the upgrade; unmanaged processes also need a
manual restart. To keep integration setup manual on that second run and future
updates, use:

```bash
HERDR_WORLD_SKIP_INTEGRATIONS=1 herdr-world update
```

Integrations you explicitly removed stay removed, and your own skills are
preserved. You can manage them in **Menu → Configuration → Integrations**.
Installer and update output distinguishes installed, updated and already current.

Keep using your existing installation channel. For npm, use
`npm install --global @ivoryheart/herdr-world@0.3.0` (Node.js 22.14.0 or newer).
For Homebrew, use `brew upgrade IvoryHeart/tap/herdr-world` after the stable
Formula update merges. Standalone archives support Linux, macOS and Windows on
x64 and ARM64 and need no external Bun.

## Practical limits

- Saved-answer delivery is automatic only for newly verified local Linux
  command-line agents in supported Chat sessions. After a World restart, check
  the Outbox for old sends; they cannot resume automatically.
- Usage and expense displays are observations, not billing guarantees. Claude
  readings can lag by about a minute and trail claude.ai; estimates need a local
  price table. Some older completion marks may need reviewing again.
- World skill installation on SSH hosts is manual. Remote Windows file and Git
  tools and agent readiness checks remain unavailable. Work-item quests and
  macOS signing and notarization remain open.
