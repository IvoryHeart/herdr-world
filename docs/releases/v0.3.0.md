# Herdr World 0.3.0

Spend less time checking agents and more time moving work forward. Since 0.2.7,
World brings questions, progress and finished work together, helps you plan your
next task and keeps your workspace ready when you return.

## What's new

- **Find work faster.** Press **Ctrl+K** (**Cmd+K** on Mac) to find agents,
  rooms and actions. On a phone, choose **Find or act** in the corner view menu.
- **Answer in one place.** **Needs you** gathers questions, blocked agents and
  finished work. Reply with attachments or mark work reviewed across browsers.
- **See progress and capacity.** Town bubbles and Board cards show current
  steps. Fuel gauges, reset times, expenses and context indicators help you
  decide what to delegate next.
- **Organize a busy crew.** Search across views, move or tidy Town rooms and
  use lenses to spot idle agents or spending. The post office keeps open pull
  requests visible after their agents leave.
- **Pick up where you left off.** Questions, answers, results and more settings
  survive restarts. Minimize windows on phones or fit Chat beside your work on
  desktop. The Town Master greets you with a recap when you return.

## Upgrade from 0.2.7

Stop World and back up its entire private data directory, including SQLite WAL
files and any separately configured legacy ledger. Preserve browser storage too.
To roll back after migration, restore the matching whole-directory backup. See
[backup and recovery](https://github.com/IvoryHeart/herdr-world/blob/v0.3.0/docs/DEPLOYMENT.md#durable-questions-results-and-backups).

For a standalone installation, once 0.3.0 is published, run:

```bash
herdr-world update
```

Run it once more after upgrading from 0.2.7 to set up World skills and Claude
usage readings for configured agent tools, even when already current. From 0.3.0
onward, updates do this automatically and restart the matching running managed
service on Linux and macOS. Start World again if you stopped it for backup;
unmanaged processes need a manual restart.

To keep integration setup manual on the second run and future updates, use:

```bash
HERDR_WORLD_SKIP_INTEGRATIONS=1 herdr-world update
```

Your own skills are preserved, and integrations you removed stay removed.
Manage them in **Menu → Configuration → Integrations**.

Keep your existing installation channel: npm users run
`npm install --global @ivoryheart/herdr-world@0.3.0` with Node.js 22.14.0 or newer;
Homebrew users run `brew upgrade IvoryHeart/tap/herdr-world` after the Formula
update merges. Archives support Linux, macOS and Windows on x64 and ARM64.

## Practical limits

- Automatic saved-answer delivery supports newly verified local Linux agents.
  Check the Outbox for interrupted sends after a restart.
- Usage readings can lag and expenses are estimates. Some older completion
  marks may need reviewing again.
- Skills on SSH hosts need manual installation. Remote Windows file and Git
  tools remain unavailable; macOS downloads are unsigned and unnotarized.

See the [feature guide](https://github.com/IvoryHeart/herdr-world/blob/v0.3.0/FEATURES.md)
for controls and limits, or follow the [tutorial](https://herdr.world/tutorial/).
