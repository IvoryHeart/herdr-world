# Herdr World 0.2.0 release candidate 1

This candidate moves Herdr World to a Roamgate-derived service and Web/PWA.
Herdr remains a separate runtime. The plugin, npm, Homebrew RC Formula, and six
Linux, macOS, and Windows archives share version `0.2.0-rc.1`.

## Highlights

- Office, Tree, Graph, and Spaces show agent work in different views.
- Open terminals, files, changes, and agent history from the selected host;
  arrange Inspector windows and the Graph.
- Connect to local and OpenSSH Herdr hosts from one World service and browser
  origin. Observe multiple hosts; actions target the selected host.
- Visual Actions, agent checkout context, task summaries, and pane pins help
  follow work across views.

Test the views, local and SSH connections, selected-host actions, terminals,
files, changes, history, and PWA installation. Report defects against
`v0.2.0-rc.1`; fixes will get another RC.

## Install

Choose one channel. npm:

```bash
npm install --global @ivoryheart/herdr-world@0.2.0-rc.1
```

Homebrew (after the tap PR merges; uninstall the stable Formula first if
installed):

```bash
brew install IvoryHeart/tap/herdr-world-rc
```

For the standalone installer, set `HERDR_WORLD_VERSION=0.2.0-rc.1`. This RC does
not replace GitHub Latest or npm `latest`.

## Upgrade from 0.1.1

Stop the old World process (both use port 8787), then recreate connection
profiles; old profiles and browser preferences are not imported. Update hooks
using the removed `herdr-world task-summary --clear` option. Native Android
packaging is retired; the PWA needs a reachable World service. See the
[deployment guide](https://github.com/IvoryHeart/herdr-world/blob/main/docs/DEPLOYMENT.md)
for migration details.
