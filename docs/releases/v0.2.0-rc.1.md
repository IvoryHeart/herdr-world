# Herdr World 0.2.0 release candidate 1

This candidate introduces the new Herdr World foundation, derived from Roamgate.
One World service and responsive Web/PWA connect to a separately installed Herdr
runtime. This RC uses one version across the Linux, macOS, and Windows x64/ARM64
archives, the Herdr plugin, npm, and the Homebrew RC Formula.

## What is new

- **See agent work in four views.** Office shows agents at work, Tree organizes
  the host and agent hierarchy, Graph visualizes connections, and Spaces keeps
  terminal workspaces close at hand. Move between these views while keeping the
  selected host in context.
- **Inspect the work behind each view.** Open terminals, Files, Changes, and
  Agent History for the relevant host and agent or pane. Arrange, resize, and
  focus Inspector windows; arrange and rotate the Graph to follow larger worlds.
- **Connect locally or over SSH.** Add local and OpenSSH Herdr profiles in World.
  The service owns the connections, while the browser uses one World origin.
  You can observe multiple hosts and choose which host receives actions.
- **Keep useful agent context visible.** Visual Actions open relevant Inspectors
  or take you to a selected target in Spaces. Agent checkout context, session
  task summaries, and pane pins help you track work as agents move between panes.
- **Install the same release across desktop channels.** Six platform archives,
  the standalone installer, npm, and the Herdr plugin share the release binaries.
  Homebrew receives the RC Formula after its tap pull request is reviewed and
  merged.

## Test this candidate

Exercise Office, Tree, Graph, and Spaces with local and SSH connections. Check
selected-host actions, terminals, files, changes, Agent History, service
management, and PWA installation. Report defects against the exact
`v0.2.0-rc.1` tag; fixes will receive a new RC number before stable 0.2.0.

## Install

Choose one installation channel. For npm:

```bash
npm install --global @ivoryheart/herdr-world@0.2.0-rc.1
```

For Homebrew, after the tap PR merges, uninstall the stable Formula first if
it is installed, then run:

```bash
brew install IvoryHeart/tap/herdr-world-rc
```

For the standalone installer, set `HERDR_WORLD_VERSION=0.2.0-rc.1`. The RC does
not replace the GitHub Latest release or npm's `latest` tag. Herdr must be
installed separately.

## Upgrade from 0.1.1

Stop the old World process before upgrading; both versions use port 8787 by
default. Recreate World connection profiles after installation: old bridge
profiles and browser preferences are not imported. Update hooks that use the
removed `herdr-world task-summary --clear` operation. The native Android
package is retired; use the responsive PWA, which needs a reachable World
service and does not work offline. See the
[deployment guide](https://github.com/IvoryHeart/herdr-world/blob/main/docs/DEPLOYMENT.md)
for migration details.
