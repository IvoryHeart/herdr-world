# Herdr World 0.2.0 release candidate 1

This candidate is the first cross-platform test of the Roamgate-derived World
foundation. It uses one version for the Linux, macOS, and Windows x64/ARM64
archives, the Herdr plugin, npm, and the Homebrew RC Formula. Herdr remains a
separately installed runtime.

Test the selected-host workflow in Office, Tree, Graph, and Spaces; local and SSH
connections; terminals, files, changes, agent history, service management, and
PWA installation. Report a defect against this exact `v0.2.0-rc.1` tag. Fixes
will receive a new RC number before the stable 0.2.0 release.

Install this candidate explicitly:

```bash
npm install --global @ivoryheart/herdr-world@0.2.0-rc.1
brew uninstall herdr-world # if the stable Formula is installed
brew install IvoryHeart/tap/herdr-world-rc # after the tap PR merges
```

Or set `HERDR_WORLD_VERSION=0.2.0-rc.1` for the standalone installer. Choose one
channel. The RC will not replace the GitHub Latest release or npm's `latest` tag.

Upgrades from 0.1.1 require fresh World connection profiles; old bridge profiles
and browser preferences are not imported. The native Android package remains
retired; use the responsive PWA. See the
[deployment guide](https://github.com/IvoryHeart/herdr-world/blob/main/docs/DEPLOYMENT.md)
for migration details.
