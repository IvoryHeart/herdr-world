# Herdr World 0.3.6

This patch fixes agents that did not start from **New agent** in 0.3.5.

## Fixes and improvements

- **Claude starts in Herdr TUI rooms.** World passes Claude a short settings file path instead of typing the full status-line settings into the terminal. The shell no longer cuts off the command and waits at a `>` continuation prompt.
- **Core agents get their shell environment.** Claude and Codex can find tools added by the host's interactive shell, including bun and nvm, with login startup on macOS. Unsupported account shells retain direct discovery and launching.
- **Core-only first run works.** A fresh World data folder discovers an existing local herdr-core and saves it as the default connection, without adding a dead TUI connection.
- **Connection CLI changes apply immediately.** Add, remove or select a default connection without restarting a running loopback World service or dropping other hosts' terminals and browser sessions. Offline edits remain supported; `--restart` is still available for a managed service.
- **Hosts are one tap away on phones.** The corner view menu includes the Hosts filter and **Manage connections**, including in Zen mode.
- **Safer service cleanup and Homebrew checks.** Uninstall removes legacy World login services while preserving core's login item and unrelated services. Homebrew release acceptance checks signed herdr-core installation and preservation across World reinstallation on both Mac architectures, using the same check in the tap.

The agent and contributor guides are shorter and current. The Code view research includes a labelled synthetic prototype; this release does not install or connect a live IDE.

## Upgrade from 0.3.5

Back up World's data directory first; see [backup and recovery](https://github.com/IvoryHeart/herdr-world/blob/v0.3.6/docs/DEPLOYMENT.md#durable-questions-results-and-backups).

After 0.3.6 is published, standalone installations can run:

```bash
herdr-world update
```

Homebrew: `brew upgrade IvoryHeart/tap/herdr-world` after the reviewed Formula update merges. npm: `npm install --global @ivoryheart/herdr-world@0.3.6` (Node.js 22.14.0 or newer). The standalone, plugin, npm and Homebrew channels use the same reviewed release version. World keeps an existing herdr-core installation; the explicit update flow may upgrade an older Herdr TUI to the version verified by World.

## Practical limits

- herdr-core support is verified with core 0.1.21. Changes in later core releases wait for a World update.
- Core agents can show **Unknown / no signal** when core or the harness supplies no native status, including at signed-out Claude and Codex onboarding. This is observed with Linux core 0.1.21, Claude 2.1.328 and Codex 0.167.0; World cannot reconstruct missing status reports from Chat or Terminal output.
- Windows herdr-core is not yet tested on real Windows hardware.
- Usage readings can lag, and expenses are estimates.
- World macOS downloads are unsigned and unnotarized.

See the [feature guide](https://github.com/IvoryHeart/herdr-world/blob/v0.3.6/FEATURES.md) for controls and limits, or follow the [tutorial](https://herdr.world/tutorial/).
