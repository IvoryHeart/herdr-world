# Herdr World 0.2.2

Herdr World 0.2.2 improves workspace and tab creation across its visual views,
desktop window arrangement and mobile navigation. Herdr remains a separate
runtime.

## What's new

- **Shared creation** gives Office, Desk, Tree and Graph consistent New
  workspace and New tab actions. Creation keeps its source through pane and
  view changes, handles cold workspaces and inactive hosts, and opens the
  resulting terminal in the current view. Spaces uses the same terminal owners
  and creation path.
- **Window arrangement** adds stable snapping, all-edge resizing,
  minimize/switch, maximize/restore and tile dividers across Inspectors and
  Spaces. Opening another window preserves existing placements, and Open all
  restores dismissed or minimized windows when a grid cannot fit.
- **Mobile navigation** moves tab actions and window restoration into the
  second-row Tabs menu, keeps Arrange beside it, and removes duplicate tab
  controls. Desktop placements persist through compact views.
- **Update checks** read the default release version from GitHub API metadata;
  the verified update manifest remains part of installation.

## Upgrade

No migration is required. Existing browser window placements remain available;
mobile navigation and window controls have moved. Install through the desktop
archives, npm, the Herdr plugin, or Homebrew on Linux and macOS. See the
[deployment guide](https://github.com/IvoryHeart/herdr-world/blob/main/docs/DEPLOYMENT.md)
for setup and connection guidance.

See the [full changelog](https://github.com/IvoryHeart/herdr-world/blob/main/CHANGELOG.md)
and [security guidance](https://github.com/IvoryHeart/herdr-world/blob/main/SECURITY.md).
