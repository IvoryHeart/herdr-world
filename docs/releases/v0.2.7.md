# Herdr World 0.2.7

Herdr World 0.2.7 brings Chat, agent launching, Town and installation
improvements since 0.2.6.

World is derived from Roamgate main after v0.8.7 at
`1a81c5daa49fe49e55a5eafbe88e5d8ce94a4376` and compatible with Herdr 0.9.5
(terminal protocol 22). Herdr remains a separately installed runtime.

## What's new

- **One agent, one window:** opening an agent in Town, Board or Desk opens Chat
  when supported, alongside Terminal, Files and Changes. Town docks it on the
  right and remembers its width. Shared window controls adapt to phones.
- **Chat for ongoing work:** read earlier messages, inspect tool calls, diffs and
  test results, follow the current task and quest, or explicitly stop an agent.
  Attach files and use slash commands; Enter adds a line, Send or Ctrl/Cmd+Enter
  sends. Answer supported permission prompts and Claude Code questions with
  checked options and receipts. Long conversations and phone layouts are more
  responsive; Claude Code history works on Unix SSH hosts, and Codex reads
  compressed and archived rollouts.
- **Profiles that launch agents:** New agent starts a supported harness from an
  editable profile: role, model, permissions, starting brief and Town appearance.
  Check harness readiness and open its login instructions. Claude and Codex now
  launch after the new shell is ready, fixing the plain-terminal launch failure.
- **Teams and agent tools:** group related agents in Town and Board, with shared
  colours and spawn relationships. The `herdr-world` CLI lets agents arrange and
  pin cards, report results, ask the owner questions and undo World-side edits;
  `herdr-world --skill` prints its guide. Quests show an agent's own todo list,
  plan, goal or loop without another model.
- **A clearer Town:** rooms grow with their tabs and keep the same order as
  Spaces. Folded rooms show the first 24 tables; **» +N** reveals more and flags
  hidden agents needing attention. Fold and Expand respond immediately after a
  tap, without waiting for background layout settling. Summary brings attention, host and room counts
  and model spend together. Pins and host/workspace colours help keep your place.
- **Attention and layout controls:** chimes distinguish who needs you and why;
  Watching, Muted and Focused control each agent's sound. All four views open in
  Zen with a floating view picker; turn Zen off in the menu for navigation bars.
- **Work beside agents:** Board's Work lens and Town badges show GitHub pull
  requests and Jira tickets. PR details show head checks, reviewer results and
  readiness evidence, with confirmed merge, close and mark ready actions. Chat
  can show known PR announcements and offer to ask their author for a fix.
- **Recovery and terminal fixes:** mobile backgrounding and reconnects preserve
  windows and unsent drafts without replaying input. Failed SSH hosts remain
  visibly stale, with Reconnect and automatic recovery. Terminal paste, links and
  keys are more reliable; stale Files previews recover without closing the window.
  Board Send rechecks session loss and honours the explicitly confirmed recipient.
- **Updates stay discoverable:** each available World version notifies once per
  browser profile and World origin, across windows and reloads. Dismissing it
  keeps the Menu attention dot and **Upgrade to <version>** action; a failed
  upgrade keeps a retry. When persistent browser storage is blocked, notification
  deduplication lasts only for the current page.

## Upgrade from 0.2.6

Preserve your World configuration and connection profiles. Existing 0.2.x
profiles, settings, login credentials and browser storage continue to be used.
Existing agent groups migrate automatically. Chat replaces the History tab;
its Details view retains the history tools. **Menu → Agents open** selects
Terminal if you prefer it to Chat.

Install this exact version through npm:

```bash
npm install --global @ivoryheart/herdr-world@0.2.7
```

Or use this release's standalone archive or Unix installer, with
`HERDR_WORLD_VERSION=0.2.7`. npm requires Node.js 22.14.0 or newer. The six
Linux, macOS and Windows x64/ARM64 archives remain. Stable releases use npm's
`latest` tag and GitHub Latest. Homebrew's `IvoryHeart/tap/herdr-world` Formula
becomes available after its tap PR is reviewed and merged.

**Herdr installation now follows World:** the standalone installer and World
updates install or upgrade Herdr to World's verified 0.9.5 release, refresh the
Codex, Claude Code and Pi integrations that are present, and pin a GitHub-installed
World plugin to the matching tag. The Homebrew tap follows the missing-only policy:
on first normal World launch it reuses existing Herdr, or installs a separate
verified prebuilt Herdr if absent. It does not require a second Homebrew-managed
runtime or an Intel source build.
With npm or a Windows archive, run
`herdr-world herdr upgrade --install`. Set
`HERDR_WORLD_SKIP_HERDR=1` for a World-only standalone install.

Check the upgrade result: World verifies downloads and never downgrades a newer
Herdr. Automatic server handoff is limited to Linux servers proven unsupervised;
follow reported restart or package-manager instructions. Windows upgrades use
Herdr's installer and migrate the older World-managed location. Plugin installation
also tolerates transient Windows staging-file locks.

See the [deployment guide](https://github.com/IvoryHeart/herdr-world/blob/v0.2.7/docs/DEPLOYMENT.md)
for installation channels, services and Herdr upgrade details.

## Known limits

- Herdr cannot make prompt input conditional on an unchanged recipient. Chat
  answers and Board sends check before submission, but a concurrent replacement
  can still receive the input. An unconfirmed or uncertain receipt needs
  inspection before retrying; see [issue #284](https://github.com/IvoryHeart/herdr-world/issues/284).
- Codex shared-daemon discovery is a read-only guess and cannot rule out clients
  outside the selected Herdr session. Add **Thread ID** through Codex's `/title`
  or explicitly link the session for stronger identity evidence. Unsupported or
  incomplete question menus must be answered in Terminal.
- Manage connections checks each host's running version and protocol, but offers
  no remote upgrade. Remote Windows file and Git tools remain unavailable, and
  harness readiness probes on Windows remain unsupported.
- PR readiness needs fresh evidence and can remain unknown. Cached source data
  does not prove readiness; World honours branch protection and required reviews.
