# Town art concepts (research, NOT approved)

Product research only. None of these directions is approved for Town, and the owner wants
more options before choosing one. Nothing here is built into World.

- `town-reimagined/`: three 2.5D whole-town directions (Pop-Up papercraft, Lumen, Cutaway),
  plus `paper-3d/`, a navigable three.js papercraft prototype (three.js r134, MIT, vendored).
  Run `python3 town-reimagined/serve.py` or open the folder through any static server.
- `report-town-reimagined.md`: what each direction shows and how the 3D prototype navigates.
- `report-town-art-abc.md`: the earlier A/B/C art pass on the real Town (2026-11-20).

Owner notes so far (2026-11-20): liked Pop-Up papercraft and asked for rotation (that became
`paper-3d/`), Lumen as a possible theme, Cutaway as a later 2D theme. All still unapproved.
