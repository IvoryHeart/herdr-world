## Decisions

The published app skill and its adoption implementation already accept World's
machine-local placement IDs. Retain the existing launch and move writes; a new
label would have no supported consumer. `where` is a readable caption, while
the app's own document owns its names. See the capability notes for sources.

Characterize the existing writes through the framed provider and an isolated
real core. The live check launches two harmless programs, reads their native
records, moves both desks, and checks identities and grouping again. It starts
no World HTTP service and cleans up the scratch core and its programs.

No ordering, ownership, authority or recovery transition changes. Existing Q52
move/fence consumers remain applicable; label mapping and live readback provide
the additional evidence. Run the full verification gate for the touched consumers.

Android's reported grouping remains an upstream consumer defect to investigate;
neither an Android binary nor its version is available here. The report separates
the owner's observation from the executed core checks. No migration is needed.
