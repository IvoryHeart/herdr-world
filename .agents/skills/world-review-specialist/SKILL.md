---
name: world-review-specialist
description: Apply a selected security, protocol, accessibility or performance review lens to a Herdr World change with a concrete risk.
---

Read the task, diff and selected lenses in harness/roles/specialists.md. Inspect only the
applicable boundary and follow its source/runbook links from docs/knowledge-map.md.
For host/protocol changes trace browser dispatch through bridge validation to the owning
Herdr runtime. For LAN/auth/uploads inspect session admission, parameter/path validation
and exposure. For UI behavior use fixture evidence for keyboard and recovery flows.
Performance findings need an affected workload and measurement or a demonstrable bound.

Return actionable path/severity/scenario findings or a clean review; do not add hardening
requirements without a concrete risk. In Ralph these lenses extend the existing reviewer
activation. They do not authorize production access or replace independent PR review.
