HERDR WORLD / INSTALL

Standalone / Node.js 22.14+

$ npm install --global @ivoryheart/herdr-world@next
$ herdr-world

→ open http://127.0.0.1:8787

The npm package includes the tested Linux x64, macOS ARM64, and macOS Intel bridges.

Standalone / macOS or Linux

$ brew install IvoryHeart/tap/herdr-world-rc
$ herdr-world

→ open http://127.0.0.1:8787

For a stable release, use IvoryHeart/tap/herdr-world. Stable and RC Formulae cannot be installed together.

Herdr-managed / Herdr 0.8.2+

$ herdr plugin install IvoryHeart/herdr-world --ref v0.1.0-rc.8
$ herdr plugin action invoke open --plugin ivoryheart.herdr-world

Install registers and builds the plugin. The startup hook starts the bridge on the next Herdr server restore; open starts it now and requests the browser. Herdr itself is never installed or started by the plugin.

CLI / after installation

$ herdr-world --help
$ herdr-world --port 8791

# Herdr plugin users:
$ herdr plugin action invoke status --plugin ivoryheart.herdr-world
$ herdr plugin action invoke doctor --plugin ivoryheart.herdr-world

The Herdr plugin intentionally uses Herdr’s action menu and CLI namespace; it does not install a second global herdr-world executable.
