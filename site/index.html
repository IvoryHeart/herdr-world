Herdr.World

Visual control plane for Herdr

Run a crew of agents. Know who needs you next.

Herdr keeps your coding agents alive in real terminals. Herdr.World puts every local and SSH host into one shared view: a town where working agents sit at their desks and show what they are doing, while questions and finished work wait at reception. Every agent is one click from its chat, terminal, files and changes.

Spend your attention where it helps

More agents, less checking.

Running several agents at once should not mean cycling through terminals to find out which one is stuck. World watches them for you and brings the next decision to the front.

Needs you

Answer the agent that is waiting, not the one you happen to be looking at.

Questions, blocked agents and finished work collect in one Needs you list in every view, and their agents walk to their building's reception. Answer from the list, attach a file or screenshot, or open Chat. Press N for the next agent that needs you.

  • Mark finished work reviewed once; the mark follows you across views and browsers.
  • The Town Master greets each visit with Since you left.
  • The browser tab and app icon show how many agents need you.

Live progress

See what every agent is doing without opening it.

Working agents show their current step in a thought bubble: editing a file, running tests, reading, searching the web or thinking. Zoom in for the detail. A step that runs unusually long turns amber, so a stuck test run stands out before it costs you an hour.

  • Board cards show the same steps, review state and idle time.
  • A sweat drop marks an agent whose context is 85% full or more.
  • Lenses colour Town and Board by idle time, spend, pull requests, quests or tool.

Ready when the next task starts

Give your agents a town.

Choose one installer, then run herdr-world and open the URL it prints. Homebrew covers macOS and Linux; npm also covers Windows with Node.js 22.14+. The standalone script works on macOS and Linux, and installs or upgrades Herdr to the verified release; set HERDR_WORLD_SKIP_HERDR=1 to leave yours untouched. Homebrew reuses existing Herdr and installs it on first launch only if missing. With npm, run herdr-world herdr upgrade --install.

From daemon to dashboard

Running in three steps.

Herdr.World connects your browser to the Herdr runtime you already use. Your agents still live in real terminal sessions owned by Herdr.

  1. 1

    Herdr keeps agents alive

    Start the coding agents you already use. Herdr owns their terminal sessions, even when your browser or laptop disconnects.

  2. 2

    Herdr.World connects locally or over SSH

    Run one World service on your computer. It connects to local or SSH Herdr hosts and serves the browser UI from one origin. Hosts filters the overview, while host-owned terminals, files and changes always open on the host that runs them.

  3. 3

    Your browser becomes the cockpit

    Open the printed URL from desktop or mobile, or install it as a PWA. Add the World skill so agents ask questions, save results and report their tasks through World.
