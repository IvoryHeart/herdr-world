### Added

- **Shell** in an agent's Town or Board peek opens its room's floating shell on
  either runtime: Herdr Float on Herdr, and on herdr-core, which has no plugin
  popups, World's own float shell. Core runs it in the agent's folder, one per
  room and shared by every browser; hiding keeps it running and **End shell**
  ends it. Herdr's apps list it as an unplaced `world-float-…` terminal.
