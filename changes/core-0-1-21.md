### Added

- Warn in Manage connections when a herdr-core host stops its programs at
  logout (core 0.1.21 or later, Linux with systemd lingering off), with the one
  `sudo loginctl enable-linger` command to run there. The warning clears by
  itself once lingering is on.

### Changed

- Match core 0.1.21, where watching never sizes a terminal: an unviewed
  terminal keeps its size while World watches it. Older cores' move to the
  headless size is still reported.
