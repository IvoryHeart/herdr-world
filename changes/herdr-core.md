### Added

- Use herdr-core beside Herdr (TUI), locally or over Unix/Windows SSH. Add an
  existing core in Manage connections; World never starts it while reconnecting.
  Both runtimes appear in Town, Board, Desk and Needs you, each once. Core
  status comes from its own reports, with Herdr’s harness names and app aliases.
- Start agents in a connected core by default, kept and placed in Herdr’s apps;
  choose a TUI room for a TUI launch. Plain shells stay unplaced. World owns its
  core rooms separately from the apps. Close/bin confirmations name the native
  kill cascade; World refuses observed additions or replaced programs and names
  any extra descendants core ends while carrying out the kill.
- Chat, send messages, answer prompts and receive saved ask answers through
  core’s send/keys for every supported harness. Replaced programs or missing
  foreground evidence refuse delivery; uncertain sends never retry. Core still
  owns the window in which an already queued send can reach a replacement shell.
- Share seen and favourite with Herdr’s apps. A foreground Town or Board peek
  clears Done there too; marking unread elsewhere is respected for that look.
  Core status events drive Web Push; World’s review marks and desk/card pins
  stay World’s own.
- Watch a live core terminal at its app’s grid without resizing it. Type to
  take the size; leaving, closing or idling gives it back. Phone composition
  and uploads work on the core host, and drafts survive reopening within the
  same connection generation.
- Open Files and Changes, transfer files and manage Git worktrees for core
  agents with the same guarded host tools as TUI agents. Ranger can read core
  rooms, create worktrees and send previewed prompts. Verified core callers can
  ask questions, publish task summaries and stamp display-only spawn relations.
- Open a core room’s shared floating shell from its agent’s peek. Hiding keeps
  it running; End shell ends it. Windows SSH uses fixed PowerShell named-pipe
  scripts and refuses a core pipe exposed to another account.
- Check the newest official core with a daily or manual release smoke that
  verifies its checksum and exercises live traffic without installing or pinning
  it. Every release retains full read-write support; failures flag work to fix.
- Read core-agent conversations with the same eight transcript readers as TUI
  Chat, with an explicit session link when needed and clear platform limits.

### Fixed

- Accept native core addresses such as `t1b` across observation, terminals,

- Offer every Herdr integration, detection and desktop harness in the core
  launcher; resolve Cursor, Antigravity, Kiro and alternate executable names.
- Send profile briefs for other core harnesses through native fenced delivery,
  only when core confirms idle immediately before typing; leave unknown or
  blocked startup dialogs untouched and retain the started agent's identity
  when brief delivery is uncertain.
