### Changed

- Releases use three owner steps: merge the release PR, tag its merge commit and merge the automatic Homebrew tap PR; CI publishes sealed, installed-channel-tested bytes and resumes partial publication automatically.
- Ordinary server PRs use Linux checks, native checks follow packaging inputs and nightly signals, and pre-push checks only formatting and privacy.

### Fixed

- Homebrew services follow a stable opt path and running upgrades refresh their service before removing the previous keg.
